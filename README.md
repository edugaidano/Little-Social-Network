# Little-Social-Network

A project by Eduardo Andres Gaidano Riquel

## Introduction

Little Social Network is a distributed application that implements a simplified social network using a Client–Server architecture. The primary objective of the project is to enable communication between multiple users through personal profiles and a private messaging system, with a strong emphasis on network infrastructure, data persistence, and modular software design.

The project is developed in C++20 and is organized into independent modules, making the system easier to maintain, extend, and evolve over time.
